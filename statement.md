# Movie Ticket Booking System

## Problem Statement

I want to make a simple movie ticket booking program using Python. The program should allow a user to see the available movies and select one of them.

After selecting a movie, the program should show its available show timings and ticket price. The user can then select a show and enter the number of seats they want to book.

The program should calculate the total ticket amount based on the number of seats and the ticket price. It should also ask for the customer's name and phone number.

After the booking is completed, the program should generate a Booking ID and show the booking details. The user should also be able to use the Booking ID to view the booking.

If the user wants to cancel the booking, the program should provide a cancellation option. The seats from the cancelled booking should be added back to the available seats.

## Main Objectives

The main objectives of this project are:

1. To show the available movies.
2. To allow the user to select a movie.
3. To show the available timings for the selected movie.
4. To allow the user to select a show timing.
5. To calculate the total ticket price.
6. To keep track of the available seats.
7. To take basic customer details.
8. To generate a Booking ID.
9. To display the booking details.
10. To allow the user to cancel a booking.
11. To update the available seats after cancellation.

## Expected Result

The expected result is a simple Python program through which a user can book movie tickets, check the booking details and cancel a booking. The project also helps in using basic Python concepts in a practical program.
