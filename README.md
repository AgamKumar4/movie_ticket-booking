# Movie Ticket Booking System

## About the Project

This is a small Python project for booking movie tickets. I made this project to practice the Python concepts that we learned in class.

When the program starts, it shows a list of movies. The user can select a movie and then choose one of its available show timings. The ticket price is also shown.

After that, the user can enter the number of seats they want. The program calculates the total amount and takes the customer's name and phone number. A Booking ID is generated after the booking is completed.

The program also has options to view a booking and cancel a booking.

## Features

- Display available movies
- Select a movie
- Display show timings
- Select a show timing
- Display ticket price
- Book seats
- Calculate the total amount
- Enter customer details
- Generate a Booking ID
- View booking details
- Cancel a booking
- Add cancelled seats back to the available seats

Open `movie_booking.py` in Python or Jupyter Notebook and run the program. Then enter the options asked by the program.
